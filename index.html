The Charter

Write a commons that governs itself.

Eight principles, worked out by hand, then signed so only the holder of the seal can change them, and every amendment is a new signed version.

Recorded.

A recorded charter is public and tamper-evident: it is signed by a key you hold (the signature is the adopting body's seal) and broadcast to several independent relays, so no single platform can recall it. It is durable, not eternal: the record lives as long as one relay keeps a copy. No outsider can alter it, and the holder of the seal amends it only by publishing a new signed version, so the history stays visible. Anyone with that secret key can replace the charter, so guard it. Drafting here keeps nothing on a server; only you decide when to record it. Built on Elinor Ostrom's eight design principles for enduring commons.
